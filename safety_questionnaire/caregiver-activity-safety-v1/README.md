# Caregiver activity-suitability questions v1

This catalogue contains four observations used only to filter activities for hearing, vision, fine-motor and gross-motor compatibility. They are separate from the checkpoint and 15 developmental inputs used by the frozen ML models.

The researcher reports that a pediatrician reviewed the question wording, response mapping, checkpoint examples and filtering rules on 2026-10-10. The repository does not store the reviewer's identity or independently inspected written evidence.

`NO_CONCERN_REPORTED` means only that the caregiver did not report a concern. It is not evidence that an ability has been clinically established and does not satisfy an activity requirement marked `required`. Missing input is invalid at the activity-retrieval boundary; `UNKNOWN` is an explicit valid answer handled conservatively.

These dimensions do not cover choking, water, stairs, falls, heat, sharp tools, appliances, allergies, hygiene, material condition or supervision requirements. Those hazards remain activity-level review matters.
