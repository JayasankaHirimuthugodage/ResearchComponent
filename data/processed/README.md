# Processed modelling data

This folder contains a locally supplied, privacy-sensitive processed modelling dataset for the SLC research component.

- Do not commit, transmit, upload or publish the CSV.
- Do not include participant identifiers, raw questionnaire answers or sensitive profile fields in logs, error messages or LLM prompts.
- The current repository does not contain the original raw survey export.
- Reproducibility is limited because no raw-to-processed feature-generation pipeline was supplied.
- Do not reconstruct, reverse-engineer or fabricate a raw dataset from the modelling file.
- Do not clean, re-save, reorder, encode or otherwise transform the supplied CSV in place.

The recorded checksum and aggregate audit evidence are in [`docs/data-audit.md`](../../docs/data-audit.md).
